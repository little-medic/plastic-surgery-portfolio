# Dr. Adrian Vale — Plastic Surgery Portfolio

A premium editorial-style portfolio website designed for a fictional plastic and aesthetic surgeon, Dr. Adrian Vale.

The project combines a luxury medical aesthetic with cinematic animations, interactive case studies, and a responsive experience across desktop and mobile.

## ✦ Features

* Cinematic animated hero section
* Scroll-driven animations with GSAP & ScrollTrigger
* Smooth editorial layout and typography
* Interactive procedure showcase
* Featured case studies
* Interactive Before / After image comparison
* Surgeon profile section
* Interactive patient testimonials
* Responsive design for desktop, tablet, and mobile
* Fixed navigation menu
* Image parallax and hover interactions

## 🛠 Tech Stack

* React
* TypeScript
* Vite
* GSAP
* ScrollTrigger
* Lenis
* CSS
* Google Fonts

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

Navigate to the project:

```bash
cd YOUR-REPOSITORY
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
